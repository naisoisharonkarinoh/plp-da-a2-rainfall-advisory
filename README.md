# Rainfall Analysis and Planting Advisory

* This project uses NumPy to clean and analyze monthly rainfall data from Nairobi, Nakuru, Kisumu, Mombasa, and Machakos and identify rainfall patterns for planting advice.
* Run `rainfall_analysis.ipynb` in Google Colab or Jupyter Notebook from top to bottom to reproduce the cleaning, rainfall calculations, planting windows, and CSV summary.
* The planting advisory recommends using the two consecutive months with the highest combined rainfall in each county as a guide, while considering local conditions, forecasts, and the data-quality limitations noted in the analysis.
